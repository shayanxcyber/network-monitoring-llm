# Project Setup

This document will contain the confirmed instructions for installing and running the project.

## Reference Environment

The current reference environment is Ubuntu 24.04 LTS. Project tools and dependencies will be added after they have
been installed and verified.

## Setup Information to Record

- Required operating system and resources.
- Python version and dependencies.
- Network simulation and packet-analysis tools.
- LLM or API configuration.
- Application launch commands.
- Test and evaluation commands.

API keys must be stored locally using environment variables and must not be committed to Git.
