# LLM Integration and Operator Interface

This component handles the LLM and the interface used to interact with it.

## Responsibilities

- Configure the selected local model or hosted API.
- Develop prompts and structured model responses.
- Integrate the LLM with the rest of the application.
- Build the query, results and operator-feedback interface.
- Display network evidence, explanations and recommendations.
- Handle invalid responses and insufficient evidence.
