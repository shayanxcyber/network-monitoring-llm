# Team Roles

Status: Proposed for team discussion. Add names only after the team agrees.

| Role | Main responsibility | Team member |
|---|---|---|
| LLM Integration and Operator Interface | Configure the model/API, develop prompts and structured outputs, integrate the LLM, and build the query, results and feedback interface |  |
| Network Environment and Traffic Simulation | Configure the Linux environment, build simulated topologies, generate traffic and produce labelled PCAPs/logs |  |
| Packet Analysis and Deterministic Detection | Process PCAPs/logs, create structured evidence, validate data and implement transparent detection rules |  |
| Application Workflow, Audit and Data | Connect packet input, parsing and detection; pass evidence to the LLM component; store timestamped results and manage configuration |  |
| Safe Network Response and Control | Validate recommendations, implement dry-run and approval controls, apply safe lab actions, and provide verification and rollback |  |
| Evaluation, Testing and Reproducibility | Test accuracy, safety, resource usage and failure cases; maintain integration tests and reproducible setup instructions |  |

All members also contribute to documentation, integration, project reporting and evidence of individual work.
